# Síntesis académica y profesional

## Título sugerido

**Automatización del procesamiento de fichadas laborales mediante Python: validación de datos y control de excepciones para RRHH**

## Resumen breve

Se desarrolló un procedimiento automatizado para transformar los archivos de marcaciones de un reloj de asistencia en reportes quincenales de control. La solución utiliza Python y Pandas para ejecutar un flujo ETL: lectura de datos heterogéneos, normalización temporal, detección de duplicados, validación de secuencias Entrada–Salida y aplicación de reglas de negocio parametrizadas. Los resultados se consolidan en Excel y CSV con trazabilidad de registros computados, excluidos y pendientes de revisión. El proyecto aborda un problema de calidad de datos y control interno mediante una herramienta reproducible, reduciendo tareas manuales sin reemplazar la validación del área de Recursos Humanos.

## Cómo explicarlo oralmente (aprox. 45 segundos)

«Desarrollé una automatización en Python para procesar los registros de entrada y salida del personal. A partir de un Excel descargado del reloj, el programa depura los datos, detecta fichadas duplicadas o inconsistentes y calcula las horas correspondientes a cada quincena. También controla jornadas atípicas: las superiores a 14 horas se revisan y las que superan 17 horas no se computan automáticamente. Finalmente, genera reportes auditables para RRHH, separando lo calculado de los casos que requieren intervención humana. El valor del proyecto está en mejorar la calidad de los datos, la trazabilidad y la eficiencia operativa».

**Conceptos asociados:** automatización administrativa · ETL · Pandas · calidad de datos · reglas de negocio · trazabilidad · controles internos · gestión por excepciones.
